# Personal Portfolio Website

A fast, lightweight single-page personal portfolio designed to showcase projects, background, and contact details with zero bloat.

👉 **[Launch Live Site](https://bytecyro.github.io/Project-Portfolio/)**

## ⚡ Quick Start

No installations, build steps, or package managers required. Just open `index.html` in any browser or visit the live link above.

---

## ✨ Features

- **Responsive Single-Page Layout:** Smoothly adapts across mobile, tablet, and desktop viewports.
- **Three Core Sections:** Clean division between **Main** (hero & introduction), **About Me** (bio & skill tags), and **Projects** (curated project cards).
- **In-Page Jump Navigation:** Fixed header with anchor links for immediate section scrolling without reloading.
- **Zero-Dependency Architecture:** Written entirely in vanilla HTML5 and CSS3 for instant load times and 100/100 Lighthouse performance.
